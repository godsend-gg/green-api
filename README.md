# MAX chat · GREEN-API

Небольшой React-интерфейс для отправки и получения текстовых сообщений в MAX через GREEN-API. Проект выполнен как тестовое задание: только необходимый сценарий, без серверной части и лишней продуктовой логики.

## Что умеет

- Проверяет `idInstance` и `apiTokenInstance` перед входом.
- Создаёт чат по номеру получателя и отправляет текст до 4 000 символов.
- Получает входящие уведомления методом `receiveNotification`, обрабатывает текстовые сообщения и подтверждает их через `deleteNotification`.
- Показывает локальный статус исходящего сообщения: отправляется, отправлено или ошибка.
- Хранит реквизиты только в `localStorage` браузера; выход очищает их и историю текущей сессии.
- Работает на узких экранах без отдельной мобильной версии.

## Запуск

Требуется Node.js 18+.

```bash
npm ci
npm run dev
```

Откройте адрес, который выведет Vite (обычно `http://localhost:5173`). Для production-сборки используйте:

```bash
npm run build
```

## Ограничения

Это клиентское тестовое приложение, поэтому токен неизбежно находится в браузере пользователя. Для production-системы вызовы GREEN-API и хранение секретов следует вынести на сервер.
